Dashboard Guide

A quick explanation of what each control does.

Add ID

Add a UID + password or an access token. Each saved record consumes one available slot.

Export IDs

Download the currently saved Level-Up records for your account. Keep exported files private.

Pause / Resume

Temporarily pause an account worker without deleting its saved record. Resume it when needed.

Refresh / Restart

Refresh retrieves the latest account information; restart restarts that account's worker.

Access expiry

When a timed access period reaches zero, the dashboard redirects to login and the server blocks expired authentication.
